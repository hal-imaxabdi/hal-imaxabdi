### <img src="https://api.iconify.design/lucide/user.svg?color=%238b949e" height="20" alt=""> About me

I write APIs and full-stack apps, then switch sides: reading logs, writing detections and attacking my own code to see what holds up.

- **Building:** reliable backends where the database enforces the rules
- **Investigating:** SIEM hunting in Splunk and Elastic, mapped to MITRE ATT&CK
- **Testing:** large automated test suites and honest write-ups of what my tools miss
